## Overview

**McMaps** is a specialized Minecraft mod built on the Fabric loader (version 1.21.1) designed to enhance **Game-Based Learning (GBL)** environments. By integrating advanced map generation and visualization tools directly into the game, McMaps provides educators and researchers with a platform to assess student spatial reasoning, creativity, and collaboration in real-time.

This project addresses the challenge of **Assessment in Gamified Environments** by offering a way to visualize, export, and analyze the "digital footprints" students leave within a Minecraft world. It bridges the gap between open-ended sandbox play and structured educational goals.

## Pedagogical Context

This tool is designed to support the following learning methodologies:

### 1. Game-Based & Simulation-Based Learning
McMaps transforms the Minecraft world into a measurable simulation. Whether students are recreating historical cities, modeling biological cells, or planning urban infrastructure, McMaps allows the learning artifacts (the maps) to be captured and analyzed outside the game environment.

### 2. Assessment & Feedback
* **Formative Assessment:** Teachers can view map data to monitor student progress without interrupting gameplay.
* **Summative Assessment:** generated maps serve as a final artifact of the learning process, suitable for grading or portfolio submission.

### 3. Synchronous & Asynchronous Learning
* **Synchronous:** Used during live class sessions to coordinate group activities and spatial orientation.
* **Asynchronous:** Allows educators to review changes in the world map over time, tracking student contributions after school hours.

## Key Features

* **Real-Time Map Rendering:** High-performance top-down rendering of the Minecraft world using the Fabric API.
* **Lightweight Integration:** Runs on the client-side with minimal server-side impact, ensuring accessibility for standard classroom hardware.
* **1.21.1 Compatibility:** Utilizing the latest Fabric rendering features for modern Minecraft versions.

## Usage in the Classroom

1.  **Preparation:** The instructor installs the mod on the host machine or distributes it to student clients.
2.  **Activity:** Students perform their building or exploration tasks within the world.
3.  **Visualization:**
    * Press `M` (default key) to open the McMaps interface.
4.  **Review:** Use the generated maps to discuss spatial relationships, resource management, or design coherence during class debriefs.
